Important system rules, security behaviour and tips.

One Key = One Device (Multi-login Prevention)
  • The first device that successfully unlocks a key permanently binds it.
  • Any other device trying the same key is blocked with “This key is already used on another device”.
  • Works for both normal DGXEN- keys and Master Keys.
  • Same device can log in again without increasing usage count.
Admin Secrets & Security
  • Gate code field is hidden. Hold FINGERPRINT 10s on the login gate to reveal code entry.
  • Inside Security: short tap ADD FINGERPRINT / ENROLL FACE = must pass fingerprint first (if any exist).
  • Secret: hold ADD FINGERPRINT or ENROLL FACE for 10 seconds → code change box appears beside those actions.
  • Face enroll needs 1s straight look, eyes open, no side face.
  • FP / Face IDs are view-only in panel — delete only via Firebase.
  • Admin login history is listed in Security. Clearing it needs FP + Face + Code.
  • Unbind / Factory reset ask for fingerprint when enrolled. Factory reset keeps adminGate data.
Share Logs & Key Banning
  • When a second device tries a bound key, a log is created automatically.
  • Logs show: Generator Name → sended key to → Receiver (or unknown user).
  • Use BAN KEY to blacklist that key. It appears in Banned Normal Keys.
  • Click KEY BANNED again to unban the key.
  • Banned keys show “Banned: …” on the login screen (not a device ban).
Master Keys & Types
  • Unlimited — pure master key, usage tracked once per new device path.
  • Limited Uses — set max logins; each login counts (same or different user) until limit, then blocked until admin removes key.
  • Device Locked — only works on the assigned device ID.
  • Time Limited — works until expiry date/time; unlimited logins inside the window.
  • Device + Time — device locked and expires at set date/time.
  • Deleting a master key wipes usage + device tracking for that key.
Active Users vs Registered Users
  • Active Users = currently have a live (non-expired) key. Live countdown is shown on the right.
  • Registered Users = all non-banned devices that ever registered.
  • Click any name / ID / key to copy it instantly.
Banning Types
  • BAN KEY (Active / Logs / Ban Key section) — only the key is blacklisted; user can generate a new key.
  • BAN DEVICE (Registered Users) — whole device/account banned; shows reason on login/key generator.
  • Banned keys appear under Banned Normal Keys; unban from there or Logs.
  • You can set a custom reason; default is “Ban: generate a new key to continue.”
Tips & Best Practices
  • Always hard-refresh (Ctrl+Shift+R) after updating login or admin files.
  • Use the top Refresh button or enable Auto Sync for live data.
  • If a legitimate user changes phone, use System Reset → Unbind Device.
  • Clear old Share Logs with the CLEAR ALL LOGS button when needed.
  • Master keys should be kept private — they still follow the one-device rule.
