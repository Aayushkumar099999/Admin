DGXEN System Manual

1. Global Key Expiry

Controls the lifespan of every new key generated via the website. Input values in hours. Example: `2` = 2 Hours. `0.5` = 30 Minutes. Changes apply instantly to all keys generated *after* the update.

2. Master Keys

Special bypass strings (e.g., `DGXEN-VIP-1`). Master Keys never expire and cannot be banned via the normal ban tool. Smart Tracker: Usage is counted per unique device. Sharing a master key will rapidly increase its usage count, allowing you to track leaks.

3. Ban Normal Keys

Use this to blacklist a specific auto-generated key (Format: `DGXEN-XXXX-XXXX-XXXX-XXXX`). Once banned here, the key instantly stops working everywhere, even if its expiry time hasn't finished.

4. Device Tracking & User Bans

Every phone accessing the generator is assigned a hidden unique Device ID. Ban Device: Permanently blocks that phone from generating new keys OR using existing keys. Unbind (Delete): Removes their data entirely, allowing them to register fresh.

5. Factory Reset

The nuclear option. Wipes the entire Firebase Realtime Database. All users, all keys, and all bans will be permanently erased. Proceed with extreme caution.
